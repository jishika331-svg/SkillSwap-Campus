# 🔄 SkillSwap-Campus

### AI-Powered Campus Skill Exchange Platform for campus collabration

SkillSwap Exchange is an AI-powered platform designed to help college students learn from each other by exchanging skills.

Students can create a profile, list the skills they can teach, mention the skills they want to learn, and discover other students with compatible learning goals. The platform uses Google's Gemini AI to intelligently recommend potential skill-swap partners based on their skills, interests, experience levels, and learning requirements.

---

## 📌 Problem Statement

College campuses have many students with different skills and talents, but there is no centralized platform where students can easily find others who can teach the skills they want to learn.

For example:

- A student knows HTML and CSS but wants to learn Python.
- Another student knows Python but wants to improve their web development skills.

Although these students could help each other, they may never find one another.

Students often depend on friends, WhatsApp groups, social media, or random online resources to find people who can teach them.

### The problem is:

> Students have valuable skills to share, but there is no simple and intelligent system to connect students based on mutual learning needs.

---

## 💡 Proposed Solution

SkillSwap Exchange provides a dedicated campus platform where students can:

- Create their student profile
- Add skills they can teach
- Add skills they want to learn
- Discover other students with compatible skills
- Receive AI-powered skill match recommendations
- Send and receive skill exchange requests
- Get personalized learning suggestions using AI

The platform focuses on **mutual skill exchange**, allowing students to learn from one another instead of simply searching for a teacher.

---

## 🤖 How AI Is Used

Google's Gemini AI will be used as the intelligent layer of the platform.

### 1. AI-Powered Skill Matching

Gemini analyzes the skills a student can teach and the skills they want to learn.

For example:

**Student A**

- Can teach: HTML, CSS, Excel
- Wants to learn: Python

**Student B**

- Can teach: Python, JavaScript
- Wants to learn: Excel

Gemini can identify that Student A and Student B are a strong potential match.

The system can provide a compatibility score and explain why the students are suitable for each other.

### 2. Understanding Different Skill Descriptions

Students may describe the same skill in different ways.

For example:

- "Web designing"
- "Frontend development"
- "Building websites"

AI can understand the relationship between these descriptions and improve matching.

### 3. Personalized Learning Suggestions

Gemini can suggest a basic learning path based on a student's current skills and desired skills.

For example:

> "I know basic C programming and want to learn Python."

The AI can suggest suitable topics and a beginner-friendly learning sequence.

## ⭐ Key Features

### 👤 Student Profile

Students can create profiles containing:

- Name
- Skills they can teach
- Skills they want to learn
- Experience level
- Areas of interest
- Preferred availability

### 🎓 Skills I Can Teach

Students can add the skills they are comfortable teaching.

Examples:

- Python
- HTML
- CSS
- Java
- JavaScript
- MS Excel
- PowerPoint
- Graphic Design
- Public Speaking

### 📚 Skills I Want to Learn

Students can specify the skills they want to learn from others.

### 🤖 AI Skill Matching

The system recommends students who may be suitable skill-exchange partners.

Each recommendation can include:

- Match percentage
- Matching skills
- Learning compatibility
- Reason for recommendation

### 🔄 Skill Exchange Requests

Students can send a skill exchange request to another student.

For example:

> "I can teach you HTML and CSS if you can teach me Python."

The receiver can accept or reject the request.

### 🔍 Search and Filtering

Students can search for skills and filter potential partners based on:

- Skill
- Experience level
- Availability
- Interests

### 💡 AI Learning Suggestions

Gemini can provide personalized suggestions for students based on what they currently know and what they want to learn.
